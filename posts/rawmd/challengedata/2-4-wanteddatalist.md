# 2.4 S’engager sur une wanted data list

Objectif : une liste des jeux de donnée que les structures s'engagent à ouvrir dite wanted data list


# Premier pas : renseigner la difficulté du travail d'ouverture

Comment renseigner la difficulté du travail d'ouverture des jeux de données de la wish list?

* reprenez les conclusion tirées de l'étape d'évaluation du travail de mise en qualité
* cochez les cases du template de wish list si les données doivent être :
    * nettoyées
    * compilées
    * complétées
    * standardisées

- en fonction des cases cochées, renseignez par le code couleur le niveau de difficulté du travail d'ouverture 

## Deuxième pas : prendre une décision sur la Wanted Data List

Comment prendre une décision sur la liste des données que vous vous engagez à ouvrir ?

- cochez dans la colonne "Décision d'ouverture" les jeux que vous vous engagez à ouvrir
- demandez aux expert de vérifier la faisabilité de votre liste

## 1.3 Rédiger une wish list des jeux de données

Objectif : obtenir une liste hiérarchisée d’une dizaine de jeux de données que la collectivité souhaiterait et pourrait ouvrir.

### Premier pas : filtrer le catalogue de données en fonction des besoins

*Comment utiliser efficacement le catalogue de données de manière à pouvoir rédiger une wish list*

Sur le catalogue, vous verrez que les jeux de données sont classés par catégorie et par niveau de maturité :
- choisissez avec le référent de la commune une liste de thématiques qui correspond à leurs besoins
- filtrer le jeu de données en choisissant les thématiques
- option : vous pouvez également filtrer les données en fonction du niveau de maturité. Cela vous donnera un ordre d'idée de la difficulté à ouvrir le jeu de donnée. (le niveau 1 indiquant un jeu facile à ouvrir ; le niveau 4 un jeu très difficile à ouvrir)
- la liste filtrée constituera une bonne base pour le deuxième pas 

[Ressource clé](https://airtable.com/shrL54CSEAr2ArHb8 "canvaLinkButton")

### Deuxième pas : remplir le template de Wish List

*Comment utiliser efficacement le template de Wish List ?*

Ouvrez la ressource clé "Wish list" qui se trouve dans le dossier "Jour 1".

- Cochez les jeux de données issus du filtrage dans l'onglet "catalogue" du template de wish list
- Contactez le référent de la collectivité pour qu'il puisse identifier le service qui produit les données
- Notez scrupuleusement les informations de contact dans l'onglet "wish list" du template

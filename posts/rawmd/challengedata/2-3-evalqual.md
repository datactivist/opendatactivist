## 2.3 Evaluer le travail de mise en qualité 

Objectif : une grille d'évaluation des jeux de données de la wish list contenant des rapports de validation de la structure des données

### Premier pas : évaluez le travail de nettoyage

Comment évaluer le travail de nettoyage pour mettre en qualité les données ?

Regardez le nombre de cellules avec des valeurs incorrectes ou hétérogènes (lignes et colonnes). Plus elles sont importantes, plus le nettoyage sera important. 

### Deuxième pas : évaluez le travail de compilation

Comment évaluer le travail de compilation nécessaire pour mettre en qualité les données ?

Demandez-vous si les données contiennent toutes les informations nécessaire pour donner du sens au jeu de données. Si ce n'est pas la cas, il y aura un travail important de compilation à faire. 

### Troisième pas : évaluez le travail de complétion

Comment évaluer le travail de complétion pour mettre en qualité les données ?

Demandez-vous si le nombre de lignes correspond à l'ampleur du phénomène que les données représentent ?
Exemple : est-il normal de n'avoir qu'une seule école dans une commune ?

Si ce n'est pas le cas, il sera nécessaire de compléter les données de la commune avec d'autres données (ouvertes).

Comment évaluer le travail de standardisation pour mettre en qualité les données ?

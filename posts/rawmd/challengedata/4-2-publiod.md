## 4.2 Publication des données et de la fiche descriptive sur un portail open data

Objectif : des données publiées et des fiches descriptives publiées sur un portail open data

### Premier pas : créer un compte sur data.gouv.fr

Pour publier des données sur data.gouv.fr, il est nécessaire de créer un compte pour l'organisation qui produit les données. Ce tutoriel détaille toutes les étapes nécessaires. Il vous faudra au préalable avoir créé <a href="

### Deuxième pas : certifier le compte de l'organisation

Suivez le lien pour comprendre les avantages de la certification et envoyer votre demande.

### Troisième pas : compléter les métadonnées sur Data.gouv.fr et publier le jeu de données

Lors de la publication des données sur Data.gouv.fr, les informations complétées dans les fiches descriptives pourront alimenter les métadonnées. Celles-ci sont à compléter au début du processus de publication, juste avant l'import du jeu de données dans data.gouv.fr.

### Quatrième pas : publier une ressources associée au jeu de données

Pour être compris, un jeu de données a parfois besoin d'une documentation associée (lexique, signication d'une nomenclature utilisée, descriptif d'une installation de capteurs à l'origine des données, etc.). Ces fichiers doivent être publiés en tant que ressources associées au jeu de données.

Après vous être connecté au portail de la commune, rendez-vous sur le "Back Office".

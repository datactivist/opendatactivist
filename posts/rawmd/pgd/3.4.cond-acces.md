## Noter les éventuelles restrictions d'accès aux données à l'issue du projet
"Aussi ouvert que possible, aussi fermé que nécessaire" : comment identifier les données pour lesquelles des restrictions d'accès s'appliquent ?
La communicabilité des données peut être conditionnée par :
* la nature ou le type des données
* l’origine des données
* leur utilisation.

## Déterminer les différents publics qui auront accès aux données à l'issue du projet
Quels publics pourront accéder aux données à accès restreint ? S'il s’avère nécessaire de restreindre l'accès ou d’imposer un accord pour le partage de données, expliquez comment et pourquoi. Les restrictions doivent être justifiées et les plus mesurées possibles.

Dans certains cas, les règles de communicabilité précisent les conditions à remplir pour accéder aux données.

## Dans le cas de données à accès restreint, déterminer les métadonnées qui doivent être publiées
Même lorsque les données ne sont pas librement accessibles, les principes FAIR  Les métadonnées (publiées par les entrepôts…) fournissent de précieuses informations pour que d'autres chercheurs puissent connaître l'existence des données, les citer, contacter leur producteur, ou encore retrouver les articles et data papers associés aux données.demandent que ces données soient décrites et leur description accessible.
## Expliquer à quel moment les données seront rendues disponibles
Quels sont les délais de publication prévus, éventuellement après une période d'embargo ? Fixer un embargo permet de se réserver une utilisation exclusive des données pendant un certain temps. La durée doit être annoncée et justifiée.
## Indiquer les outils nécessaires pour accéder aux données
Comment les utilisateurs potentiels auront-ils accès aux données ? Dans la majorité des cas, un navigateur web suffit (protocole HTTP). Si un autre protocole a été choisi (FTP, SQL…), merci de le détailler.

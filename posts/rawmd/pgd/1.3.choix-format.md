# Pourquoi choisir tel format plutôt que tel autre ?
Les choix d’un format peuvent être guidés par l’expertise du personnel de l'organisme, ou par une préférence pour les formats ouverts, par les standards de format acceptés par les entrepôts de données, par l’usage largement répandu dans une communauté de recherche ou par le logiciel ou l'équipement qui sera utilisé.

# Chaque produit de recherche peut prendre plusieurs formats concurrents.
En équipe et avec les personnes ressources (personnel de documentation, service informatique), évaluez si le choix de format que vous avez effectué est le plus ouvert possible.

# Profitez du PGD pour choisir une meilleure option
Si une option plus ouverte se présente à vous, choisissez un autre format pour vos données.

## 3.1 - Étudier les données existantes

Comparer les jeux de données permettra de déterminer un "plus petit dénominateur commun", c'est-à-dire les champs et valeurs partagées, qui seront sans doute incontournables dans le futur standard. 

![1-1](/images/algo/1-1.png)

### Dans une base de données : rassembler des jeux de données issus de plusieurs sources  
Une première étape consiste à créer un **document central**, qui servira de référence tout au long du processus de création du standard. Ce "master document" permettra dans un premier temps de rassembler, comparer et analyser des données existantes sur le sujet traité. 

Idéalement, utilisez une base relationnelle (de type airtable table ou grist - solution open source et gratuite). Cela permettra de structurer au mieux l'information. 
Cette base pourra par exemple contenir des tables : 
* Sources de données : Cette table recense les jeux de données sur lesquels vous allez travailler. Elle contient le nom du jeu de données, du producteur, la zone géographique et/ou temporelle concernée, l'URL du jeu de données et de sa documentation, et éventuellement d'autres champs permettant de le contextualiser. 
* Champs : Cette table constitue l'inventaire exhaustif des champs présents dans toutes les sources de données. Pour chaque champ, il est important de noter : nom exact, type (texte libre, valeur contrainte, date...), description, caractère obligatoire ou non. Une liaison doit être faite avec la source de données. 
* Groupes de champs : Cette table permet de regrouper des champs proches (selon leur fonction ou leur objet). Par exemple, tous les champs liés à la localisation d'un lieu (adresse, code postal, ville, coordonnées GPS...) seront regroupés dans un champ "Localisation". Ce travail de regroupement peut être fait en s'appuyant sur une IA, mais il est impératif d'effectuer un contrôle humain pour s'assurer que le rapprochement conceptuel entre champs est cohérent.  
* Valeurs : Cette table recense les valeurs utilisées dans les champs à listes contraintes. Elle est essentielle pour comprendre comment les différents producteurs décrivent des objets, et selon quelle granularité. Par exemple, si vous travaillez à standardiser des données relatives à des lieux offrant des services, avoir une liste exhaustives desdits services est essentielle. Dans le processus de standardisation, des choix seront opérés sur la base de la liste de valeurs que vous aurez établies lors de cette phase d'analyse (ne la négligez donc pas !).

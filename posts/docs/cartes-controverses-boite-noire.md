# Conseils pour l'impression
- Format A4, impression à 100%, conserver les proportions. À découper suivant les pointillés
- Impression cartes : recto verso bord long
- Les guides de découpe sont visibles sur les fichiers PDF
- Une fois imprimées et découpées, les cartes peuvent être plastifiées pour une meilleure durabilité

# Quand les controverses s'activent

Les cartes controverses s’activent lorsque le pion passe par une case de controverse sur l’échelle de score (case n°21, 29, 37, 44, 53, 60, 67). Quand le pion passe par l’une de ces cases, le jeu s’arrête : le groupe doit débattre et trancher avant de reprendre le placement des cartes action.

Les consignes d'animation de cette étape sont dans les [consignes d'animation](/docs/consignes-animation-boite-noire) (étape 2.3).
